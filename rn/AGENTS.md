# Money RN

The React Native (Expo SDK 58) version of Money, installed next to the WebView app as `com.yashdobal.money.rn`.

- **Nothing personal in the code.** Banks, cards, salary figures and the plan come from the signed-in account's saved
  settings (`profile` and `cfg`, see `applyProfile` in `app/engine.js`); tests use the invented demo data.
- **The maths is the website's.** `src/engine.gen.js` is generated by `node tools/rn_engine.mjs` from `app/engine.js`,
  `app/shape.js` and the collector's rules; never edit it. Screens read figures from it (`E.heroModel()` …) and change
  things through `E.act.*`; `tools/rn/engine.test.mjs` checks it gives the server's numbers.
- **No Expo account.** GitHub builds the APK (`.github/workflows/rn.yml`): `expo prebuild` then Gradle, signed with the
  Money app's key from the repository secrets. `android/` is generated (Continuous Native Generation): change native
  behaviour in `app.json`, `plugins/with-money.js` or `modules/money-native` (a local Expo module), never by hand.
- **Navigation** is a small store (`src/nav.js`), not Expo Router: five tabs, Settings, and bottom sheets
  (`src/sheets.js`), with links like `moneyrn://today?sheet=add` from shortcuts, the widget and alerts.
- **Look:** bento, the same as the website (`app/app.css`): colours from `src/theme.js` (signal blue by default,
  Minimal, seed palettes, or the phone's Material You palettes through `modules/money-native`), and the building
  blocks in `src/kit.js`. A `Panel` is a grey tray whose `Row`s and `Tile`s are white cards (`TrayCtx` tells them what
  they sit in); `kind="w"` is one white card (charts, forms), `kind="d"` a dark card. Type is Anek Latin, cut by
  `tools/rn/fonts.py`. `src/alive.js` keeps every card moving a little while its screen is showing.
- Packages: `npx expo install` can't reach Expo's servers here, so install the versions in
  `node_modules/expo/bundledNativeModules.json` with `npm install`.
- **It is also the website** (and what the older Android app shows): `python3 tools/build_site.py` builds it for the
  browser into `dist/`. Anything that differs between the phone, a browser and the Android app's WebView goes in
  `src/host.js` or a `src/native/*.web.js` file (Metro picks `.web.js` in the browser), never in a screen. On a wide
  window (`useWide()`, 980 px and up) screens sit in `Page` (two CSS columns) beside a sidebar. Animated loops in the
  browser are CSS animations made through `StyleSheet.create` (an inline style drops `animationKeyframes`).
  Check it with `node tools/ui/site.test.mjs`.
- Check screens: `npx expo export --platform web --output-dir dist-web`, then `node tools/ui/rn.shots.mjs`.
